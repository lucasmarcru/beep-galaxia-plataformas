Controles: usa los botones para mover a Beep entre posiciones, saltar, activar el propulsor y disparar. Elige uno de los tres planetas para cambiar el escenario. Las patrullas y los efectos se mueven con animaciones CSS. Es una demostración visual: HTML y CSS no permiten las físicas, la detección de choques ni los controles de teclado y ratón de un juego completo.
