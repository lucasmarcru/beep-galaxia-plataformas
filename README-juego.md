# Beep: misión galaxia

Demostración visual de plataformas creada únicamente con **HTML y CSS**.

## Escena

- Tres escenarios seleccionables con colores y ambientes distintos.
- Controles en pantalla para cambiar la posición de Beep, simular un salto, activar propulsores y mostrar un disparo.
- Rivales y efectos con animaciones CSS.

## Límites

Es una escena interactiva sencilla, no un juego completo. Sin JavaScript, HTML y CSS no permiten implementar físicas, colisiones, inteligencia de enemigos ni controles de teclado y ratón propios de un juego de plataformas.
